# RAG на Weaviate

День 1 загружает локальную базу знаний и очищает текст. День 2 режет очищенный текст на чанки. День 3 считает эмбеддинги локальной моделью и складывает чанки в Weaviate. День 4 ищет по вопросу ближайшие чанки. День 5 отвечает на вопрос только по найденным фрагментам.

## Установка

```bash
uv sync
```

Эмбеддинги считает `deepvk/USER2-base` с Hugging Face, локально. Если PyTorch видит GPU, расчёт идёт на CUDA, иначе на CPU. Первый запуск скачивает веса модели.

## Weaviate

```bash
docker compose up -d
```

Сервис слушает `localhost:8080` (HTTP) и `localhost:50051` (gRPC). Анонимный доступ, без встроенного vectorizer: векторы считает приложение.

## Список документов и примеры чанков

```bash
uv run python main.py
```

Команда печатает имя каждого файла и длину очищенного текста в символах, затем число чанков и три первых чанка с метаданными.

Размер чанка — 800 символов, перекрытие — 150. Окно скользит по символам: соседние чанки делят ровно 150 символов хвоста и начала.

## Загрузка в Weaviate

```bash
uv run python main.py ingest
```

Команда заново создаёт коллекцию `KnowledgeChunk` и записывает все чанки с эмбеддингами и метаданными (`document_id`, `source_name`, `chunk_id`, `text`). Повторный запуск не копит дубликаты: коллекция удаляется и заполняется заново. В конце печатаются устройство, число объектов и один объект из базы.

## Ответ на вопрос

Нужны переменные в `.env`: `OPENROUTER_API_KEY` и `OPENROUTER_BASE_URL`. Модель по умолчанию — `openai/gpt-4o-mini`. Её можно сменить переменной `LLM_MODEL`.

```bash
uv run python main.py ask "На сколько дней выдают обычные книги?"
```

Команда считает эмбеддинг вопроса той же моделью, что и при загрузке, берёт из Weaviate 5 ближайших чанков и просит LLM ответить только по ним. Модели запрещено добавлять факты вне этого контекста. Если фрагментов нет, LLM не вызывается.

Печатаются ответ, список источников (`source_name` и `chunk_id` каждого переданного чанка), затем сами фрагменты: `score`, `distance` и начало текста.

`distance` — косинусная дистанция Weaviate: `0` значит, что векторы совпали. `score = 1 - distance`, поэтому большее значение — более близкий фрагмент. `source_name` — файл базы знаний, из которого взят чанк.

```bash
uv run python main.py ask "На сколько дней выдают обычные книги?" --compare
```

Флаг `--compare` добавляет второй ответ той же модели без документов. Его удобно сверить с ответом по контексту: без поиска модель не знает правил этой библиотеки.
