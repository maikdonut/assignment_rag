# RAG на Weaviate

День 1 загружает локальную базу знаний и очищает текст. День 2 режет очищенный текст на чанки. День 3 считает эмбеддинги локальной моделью и складывает чанки в Weaviate.

## Установка

```bash
uv sync
```

Эмбеддинги считает `deepvk/USER2-base` с Hugging Face, локально. Если PyTorch видит GPU, расчёт идёт на CUDA, иначе на CPU. Первый запуск скачивает веса модели.

## Weaviate

```bash
docker compose up -d
```

Сервис слушает `localhost:8080` (HTTP) и `localhost:50051` (gRPC). Анонимный доступ, без встроенного vectorizer: векторы считает приложение.

## Список документов и примеры чанков

```bash
uv run python main.py
```

Команда печатает имя каждого файла и длину очищенного текста в символах, затем число чанков и три первых чанка с метаданными.

Размер чанка — 800 символов, перекрытие — 150. Окно скользит по символам: соседние чанки делят ровно 150 символов хвоста и начала.

## Загрузка в Weaviate

```bash
uv run python main.py ingest
```

Команда заново создаёт коллекцию `KnowledgeChunk` и записывает все чанки с эмбеддингами и метаданными (`document_id`, `source_name`, `chunk_id`, `text`). Повторный запуск не копит дубликаты: коллекция удаляется и заполняется заново. В конце печатаются устройство, число объектов и один объект из базы.
